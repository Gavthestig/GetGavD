# ColourForge Paintball & Grenades 0.8 — testing

[Download testing ZIP](https://github.com/Gavthestig/GetGavD/releases/download/paintball-v0.8-test/ColourForge-Paintball-and-Grenades-test.zip)

Extract the mod into your Scrap Mechanic user Mods folder and enable it in a Creative test world. Use the folder containing description.json; avoid an extra nested directory. Back up worlds before testing prototypes. This Lua shooting prototype does not require ColourForge.dll to fire paintballs.

Left mouse shoots, right mouse aims, Q opens the colour picker, Escape closes it and R reloads the 50-ball hopper. Paint marks are temporary, normally lasting 120 seconds. Paint grenades spread splats; smoke grenades create visual smoke for about 16 seconds. Grenades are unlimited prototype tools. Smoke uses a 512-colour palette approximating your selected colour and does not block bot AI targeting.

Gun shooting and surface/character marks have been user-tested. The latest smoke colour and coverage changes still need in-game verification. Dedicated grenade detonation sounds are not included. Multiplayer and Survival are unverified.

The local Challenge port requires game-level registration and additional asset paths. That portable installation is not included in this testing ZIP; do not advertise this ZIP as supporting every mode.

Editable Lua/GUI definitions are in Mods/Paintball. The complete ZIP contains the required models, textures, effects and particles. Model attribution is in CREDITS.txt and the repository’s third-party notices.
